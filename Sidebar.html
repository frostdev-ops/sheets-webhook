Placeholders & filters

Click a chip to insert a placeholder. {{_all}} sends every question and answer; {{_timestamp}} is the submission time. An empty template defaults to the full response.

Format an answer with filters, chained with pipes: {{Name|escape|bold}}

bold italic underline strike spoiler code codeblock quote list escape upper lower trim

list turns a multi-select answer into bullet points; escape makes free-text answers render literally instead of as markdown.

Everything else is plain Discord markdown: # heading, **bold**, > quote, ```code```, - list, ||spoiler||. Long messages are split and delivered in order automatically.
